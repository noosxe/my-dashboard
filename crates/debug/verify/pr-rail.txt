# pr-rail.txt — the PR Conversation rail's metadata sections over the
# committed fixtures (docs/0083 D1, D7–D12; #732, #754, #756, #799, #800):
#   101  Edit on the sections the viewer can use; the team request hides
#        Edit reviewers and says why; the Labels picker opens in place with
#        its filter focused, the rail scrolls to Save and Cancel, and Save
#        is disabled while nothing changed; Esc closes the card first. `github-pr-picker` pins the
#        open card (structural golden, 0065 D5).
#   102  the rail scrolls at 1280x800 (the 137-comment PR with 20 of 34
#        labels, 13 reviewers, 12 assignees): Edit labels is missing and
#        the reason line says why.
#   103  a draft with nothing filled in: all four sections, one-line empty
#        states, every Edit.
#   104  merged and 105 closed: no Edit anywhere, empty sections left out.
#
# Prerequisites: the containerized env (docs/0071) with the GitHub
# fixtures and the pinned clock, and a session named `prrail` at 1280x800:
#   export DASHBOARD_GITHUB_FIXTURE=/work/crates/debug/verify/fixtures/github
#   export DASHBOARD_FIXED_NOW=2026-10-23T12:00:00Z
#   dashboard-debug session start --name prrail --size 1280x800 \
#     --binary /tmp/target/debug/my-dashboard
# Run (in-container): dashboard-debug run crates/debug/verify/pr-rail.txt
# Then `dashboard-debug writes` must print nothing: no step here writes.
#
# Rows and the rail's controls take bridge mouse clicks at their centres,
# frozen for this fixture set at 1280x800 (see pr-page.txt for why).
#
# Not here, covered by unit tests next to the code (pr_page/rail): Edit
# hidden while a write is pending (a fixture write answers at once), the
# 8-row cap and "+N more" expansion, and the changed-draft Save posting
# exactly one write.
