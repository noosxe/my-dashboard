# timeline-xref.txt — the cross-reference rows of the PR page (#922) and the
# issue page (#923) over the committed fixtures (docs/0085): "octo-dev
# mentioned this pull request in …" rows in PR 101's timeline, one per
# distinct source, then their activation; then the same rows on issue 201
# ("linked a pull request that will close this issue"), the closed issue
# 198 and the capped issue 202.
#   - every row is a Button with a full accessible name (sentence, the
#     source's state, what activating does);
#   - a source in a listed repository opens in the app (focus + Enter) and
#     Back returns;
#   - a source elsewhere opens the browser: the bridge records no browser
#     opens, so the receipt asserts that the page stays;
#   - 102 carries 100 of 130 references: the cap row counts the 30 cut;
#   - on the issue page the in-app open and Back return to the *issue* (the
#     host's trail records the issue place), and an unsent comment draft
#     survives the round trip (the restored box sends it: `assert-write`).
#     The issue page has no leave guard: it emits at once. Its node ids
#     vary between runs, so the issue section finds everything by label.
#
# Prerequisites: the containerized env (docs/0071) with the GitHub
# fixtures and the pinned clock, and a session named `prxref` at 1280x800:
#   export DASHBOARD_GITHUB_FIXTURE=/work/crates/debug/verify/fixtures/github
#   export DASHBOARD_FIXED_NOW=2026-10-23T12:00:00Z
#   dashboard-debug session start --name prxref --size 1280x800 \
#     --binary /tmp/target/debug/my-dashboard
# Run (in-container): dashboard-debug run crates/debug/verify/timeline-xref.txt
#
# Rows and tabs take bridge mouse clicks at their centres, frozen for this
# fixture set at 1280x800 (see pr-page.txt); the cross-reference rows are
# found by their labels.
