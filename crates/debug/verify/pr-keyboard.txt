# pr-keyboard.txt — the PR page by keyboard (#733, #734, #768): the tab strip
# is one Tab stop that Left/Right/Home/End drive, every composer Tabs out, and
# each tab of the two stress scenarios passes the 0065 D3 audit.
#
# Prerequisites: the containerized env (docs/0071) with the GitHub fixtures
# and the pinned clock, and a session named `prkeys` at 1280x800:
#   export DASHBOARD_GITHUB_FIXTURE=/work/crates/debug/verify/fixtures/github
#   export DASHBOARD_FIXED_NOW=2026-10-23T12:00:00Z
#   dashboard-debug session start --name prkeys --size 1280x800 \
#     --binary /tmp/target/debug/my-dashboard
# Run (in-container): dashboard-debug run crates/debug/verify/pr-keyboard.txt
#
# Focus is moved by keys only. From a freshly opened page the third Tab lands
# on the tab strip (Refresh, Open on GitHub, tab strip); on Conversation of
# #101 the comment box is thirteen stops after it (the description's Edit, its
# reactions, each timeline row's buttons). `tab-stops` while a composer has
# focus is the receipt that Tab leaves it: a trapped field stops the walk at
# the first step ("focus did not advance", #733). Tabs and rows take bridge
# mouse clicks at their centres, frozen at 1280x800 (see pr-page.txt).
