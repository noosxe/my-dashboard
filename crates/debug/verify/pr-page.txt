# pr-page.txt — the PR detail page over the committed scenarios (docs/0081
# §12.1, #769): each state opens from fixture-user/beacon's Open PRs lane in
# one session, and each tab shows its content. Structural goldens pin the
# Conversation tab of the populated, draft and merged scenarios (0065 D5).
#
# Prerequisites: the containerized env (docs/0071) with the GitHub
# fixtures and the pinned clock, and a session named `prpage` at 1280x800:
#   export DASHBOARD_GITHUB_FIXTURE=/work/crates/debug/verify/fixtures/github
#   export DASHBOARD_FIXED_NOW=2026-10-23T12:00:00Z
#   dashboard-debug session start --name prpage --size 1280x800 \
#     --binary /tmp/target/debug/my-dashboard
# Run (in-container): dashboard-debug run crates/debug/verify/pr-page.txt
#
# Rows and tabs take bridge mouse clicks at their centres, frozen for this
# fixture set at 1280x800 and re-derived with `tree` when they move. Rows
# because an AT-SPI click on one does nothing and they take no keyboard
# focus yet (#657). Tabs because the ids under the PR page hash its entity
# id, so they differ between identical walks; only chrome ids are stable
# here, and goldens compare structure rather than ids (0065 D5). The tree
# has no title or commit-row nodes (#768), so the Commits stops can only
# show that the Conversation content left.
#
# Not here yet, because they would stop the walk at the first scenario:
# `audit` FAILs on the unlabeled combo boxes (#768) and `tab-stops` exits
# at the comment box's Tab trap (#733). Add both at each Conversation stop,
# after its `assert-baseline`, when those land. Until then a PR-page PR
# runs them as one-off verbs at the stop it touches.
