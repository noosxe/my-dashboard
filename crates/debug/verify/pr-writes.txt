# pr-writes.txt — the PR page's write flows over the committed fixtures
# (docs/0081 §12.1, #812): the fixture transport answers each write from a
# response file and records it, and every click is followed by an
# `assert-write` on what was recorded (docs/0010 D11). Answers are static,
# so the page after a write is still the pre-write read; what is asserted
# is the request the click sent and that the page survives the answer.
#
# Prerequisites: the containerized env (docs/0071) with the GitHub
# fixtures and the pinned clock, and a session named `prwrites` at 1280x800:
#   export DASHBOARD_GITHUB_FIXTURE=/work/crates/debug/verify/fixtures/github
#   export DASHBOARD_FIXED_NOW=2026-10-23T12:00:00Z
#   dashboard-debug session start --name prwrites --size 1280x800 \
#     --binary /tmp/target/debug/my-dashboard
# Run (in-container): dashboard-debug run crates/debug/verify/pr-writes.txt
#
# Clicks are bridge mouse clicks at the controls' centres, frozen for this
# fixture set at 1280x800 (ids under the PR page differ between walks; see
# pr-page.txt). The comment box sits below the fold, so the Conversation
# scrolls by -600 first (it bottoms out at 387px).
#
# Merge on 107 offers one method, so the recorded method is the default
# MERGE; the method caret appears only for PRs that allow several. 107's
# viewer last used squash, which its repository no longer allows, so the
# default falls back to MERGE (docs/0016 D5, #776).
#
# The last sections walk the metadata pickers on 103 (#857: open each, change
# one row, Save, assert the op and the complete replacement id list, docs/0043
# D1) and the state flips of docs/0083 D4 and D5: Ready for review on 103,
# Convert to draft through the more menu and its confirm on 113 (Esc backs out
# first), and Reopen on 114. 113's split button preselects squash, the
# viewer's default (#776). The more menu's rows have no a11y name (#862), so
# they are clicked by position.
#
# The last section walks auto-merge and the merge queue (#774, #775) on
# 117-121: Enable auto-merge with the caret's method (rebase) after a confirm
# Esc backs out of, Disable auto-merge, Merge when ready and Enable
# auto-merge on a queued base (confirms, no method), and Remove from queue.
# Clicks use the tree's window-relative bounds, which equal the mouse's.
