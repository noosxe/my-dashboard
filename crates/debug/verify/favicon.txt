# favicon.txt — docs/0064 §6's bridge receipt as a committed script:
# the favicon generator's source → styling → platform → export flow,
# driven end to end. The export dir is set via the bridge-addressable
# path field (D7 — the rfd picker is OS-level and invisible to `tree`),
# which is exactly the testability seam the design bought.
#
# Prerequisites:
#   DASHBOARD_STATE_DIR=/tmp/favicon-verify/dashboard \
#     dashboard-debug session start --name favicon --size 1440x900
#   mkdir -p /tmp/favicon-out   (fresh: no collisions on first run)
# Run: dashboard-debug run crates/debug/verify/favicon.txt
# After: /tmp/favicon-out holds favicon.svg, favicon.ico,
#   favicon-96x96.png, favicon.html (web defaults), and a second
#   run must surface favicon-overwrite-confirm before writing.
#
# What each snapshot must show (docs/0064 D2/D5/D7):
#   boot        — favicon-page with its three zones (favicon-inspector,
#                 favicon-stage, favicon-export-rail; docs/0064 §12),
#                 favicon-source-tabs, favicon-text-input,
#                 favicon-font-family (Select), the three light color
#                 fields, favicon-preview-{16,32,96,180,512} frames,
#                 favicon-context-* mocks, the favicon-export-dir field
#                 and the favicon-export button
#   edited      — text changed to "D" (set on favicon-text-input)
#   platformed  — favicon-platform-ios and -pwa checked, favicon-ios-1024
#                 visible, favicon-app-name shown (PWA on); the commit
#                 button reads "Export 9 files"
#   exported    — success toast (source "favicon"); exporting back to
#                 false; /tmp/favicon-out holds 9 files
#   re-export   — the overwrite AlertDialog (favicon-overwrite-confirm /
#                 -cancel buttons) listing the 9 collisions (never a
#                 silent overwrite); cancel leaves files intact
#
# Also covers the analytics rail: the export emitted one
# module="favicon" transport="local" op="export" record (D9) — visible
# on the usage page's transport facet after refresh.

--session favicon
